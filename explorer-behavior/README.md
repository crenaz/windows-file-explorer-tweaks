# Explorer Behavior Tweaks

This directory contains tweaks controlling global Windows File Explorer behavior, visibility options, and preferences.

## Common Planned Tweaks
- **`show-file-extensions`**: Ensures file extensions are always shown (`HideFileExt = 0`).
- **`show-hidden-files`**: Enables display of hidden files and folders.
- **`compact-view`**: Enables compact item spacing in Windows 11 Explorer.
- **`launch-to-this-pc`**: Configures Explorer to open to "This PC" instead of "Home".
