# Folder Views Tweaks

This directory contains tweaks targeting Windows File Explorer folder view templates, view mode caching, and performance optimizations.

## Common Planned Tweaks
- **`disable-auto-folder-discovery`**: Prevents Explorer from scanning code directories and erroneously applying "Music" or "Pictures" view templates.
- **`default-view-details`**: Enforces the "Details" view across all directories.
- **`reset-folder-view-cache`**: Safely clears corrupted `BagMRU` and `Bags` cache to restore default folder views.
