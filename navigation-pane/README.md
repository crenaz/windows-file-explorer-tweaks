# Navigation Pane Tweaks

This directory contains tweaks targeting the left sidebar (navigation pane) in Windows File Explorer.

## Common Planned Tweaks
- **`hide-gallery`**: Hides the Windows 11 "Gallery" node from the navigation tree.
- **`hide-network`**: Removes the "Network" node.
- **`hide-home-quick-access`**: Configures Quick Access / Home visibility.
- **`pin-custom-folders`**: Registers custom root folders using CLSID shell extensions.
